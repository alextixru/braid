# ADR 0005. Подписка — HTTPS-файл на каждом хосте с пином сертификата

Статус: принято (2026-10-29).

## Контекст

Правила и адреса движков должны обновляться у всех пользователей без действий с их стороны
(«как в Happ»), а протокольные серверы — оставаться без изменений. У хостов нет доменов,
Let's Encrypt для IP ненадёжен, а доверять любому сертификату нельзя: подписка несёт ключи.
Пользователи привязаны к одному хосту каждый (друзья — Хельсинки, админ — Франкфурт),
автопереключения между хостами нет (G09).

## Решение

Личная ссылка `braid://base64url({v:1, url, token, pin})` (`braid_proto::BraidLink`): `url` —
адрес `braid-subd` на хосте, `token` — не меньше 128 бит случайности, `pin` — SHA-256 SPKI
самоподписанного сертификата. Клиент (`braid_core::subscription::SubscriptionClient`)
забирает `GET <url>/sub/<token>.json` по HTTPS через собственный верификатор rustls
(`PinVerifier`): совпал пин — сертификат принят, иначе `PinMismatch`; корни CA не нужны.
`ETag`/`If-None-Match`, обновление при каждом подключении и раз в N часов из подписки;
последняя рабочая копия хранится локально (`Store`), при недоступности хоста работает она.
Подписка — JSON `schema = 1` (`braid_proto::Subscription`): хост, движки с параметрами по
приоритету, наборы правил и режимы, `probe.dns`, `client.latest`, у админа — `telemetry`.
Сервер `core/braid-subd` отдаёт статические файлы и принимает `POST /telemetry`
(Bearer-токен админа); 404 одинаков для чужого, кривого и отозванного токена. Файлы
собирает и выкладывает по SSH `braidctl publish` из `state/` админа.

## Последствия

- HTTPS без CA и без домена; смена сертификата хоста = новая ссылка всем его пользователям.
- Подписка доступна и напрямую, и через туннель — адрес хоста исключён из интерфейса.
- Отзыв — удаление файла: клиент показывает «Доступ отозван» (`FetchOutcome::Revoked`).
- Секреты (ключи, пароли CSQTT, токены) едут только внутри подписки по пину; хеши VK в
  подписку не кладутся — у каждого свои или вход VK.
- Проверяется без сети: `braid-subd` поднимается в тестах на `127.0.0.1`
  (`core/braid-subd/tests/e2e.rs`, `core/braid-runtime/tests/e2e.rs`).
