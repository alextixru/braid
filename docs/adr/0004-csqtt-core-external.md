# ADR 0004. CSQTT — вендоренный `csqtt-core` в режиме External

Статус: принято (2026-10-29).

## Контекст

Движок CSQTT — ядро форка FOCSQ (`luminescq/focsq`, каталог `backend/`, ветка `feat/macos`),
которое само открывает tun через root-помощник и само ставит маршруты. В Braid интерфейс один
и принадлежит роутеру (ADR 0001); ядру нужен вход и выход пакетов без tun. Лицензия ядра —
PolyForm Noncommercial 1.0.0.

## Решение

Копия ядра лежит в `engines/csqtt-core` (коммит a485014; источник, список правок и
маркировка — `engines/csqtt-core/BRAID-PROVENANCE.md`), не сабмодуль: правки живут в этом
репозитории. Каждое отличие помечено `// [BRAID]`, SPDX-заголовки сохранены. Добавлен
режим **External** (`external.rs`): `run_engine(ClientConfig, EnginePort, hooks)` — пакеты
ходят через `Dispatcher::dispatch` и очереди возврата вместо tun/UDP; хуки `on_config`
(`TUNCONF`: адрес и DNS) и `on_exclude` (адреса TURN — мимо интерфейса); публичный
`snapshot()`; отключены монитор родительского процесса и обработчик Ctrl-C; DNS ядра и
транспорт TURN настраиваемы. Стек VK/TURN/obfs/worker/session не менялся. Обёртка
`core/braid-engine-csqtt` (`CsqttEngine`) реализует `Engine`, переводит события ядра в
`EngineEvent` (капча, нужны хеши, вход VK) и держит хеши и токен только в памяти.
Ядро — не член workspace (path-зависимость; `[patch.crates-io] primp` — вендорная копия),
его тесты гоняются отдельно: `make check-csqtt`.

## Последствия

- Весь стек FOCSQ работает как есть; что умеет FOCSQ (хеши звонков, вход VK, капча) — умеет Braid.
- Один экземпляр ядра на процесс (глобалы ядра) — `braid_runtime::EngineFactory` отдаёт тот же
  `CsqttEngine`, пока он жив; смена сети — полный перезапуск ядра.
- Сокеты ядра не проходят `protect_socket` — обход только маршрутами (`VK_EXCLUDE_CIDRS`,
  адреса TURN, DNS `77.88.8.8`/`77.88.8.1`), что учтено в `TunConfig.excludes`.
- **Лицензия действует на всё, что линкует ядро**: сборки Braid с CSQTT — только некоммерческое
  использование, для себя и своих (`THIRD_PARTY.md`, экран «О программе»).
- Обновление ядра из апстрима — ручной перенос правок по списку в провенансе.
