# ADR 0012. Журнал и телеметрия — только на устройствах админа

Статус: принято (2026-10-29).

## Контекст

Заказчик: «давай логи и телеметрию только для меня как для админа, чтобы собрать статистику по качеству и стабильности работы. В остальном не надо», а позже: «Только мои устройства шлют на мой хост; у друзей ничего».

## Решение

Журнал событий — подключения, переключения с причиной и метриками, пробы, смены сети, ошибки движков — ведётся только на устройстве, подписка которого несёт признак админа. Он же включает отправку журнала на хост админа (пакетами при переключении и раз в час; пока хост недоступен, пакеты копятся и повторяются) и показывает экран «Статистика». Отправка идёт с токеном, который лежит только в подписке админа.

У остальных нет ни журнала на диске, ни отправки, ни экрана, ни лога приложения: в памяти остаётся лишь кольцевой буфер последних ошибок, а снаружи — системные отчёты ОС о падениях. Даже у админа в журнал не попадают домены и адреса — только движки, причины, сети и метрики. Сводку по файлам на хосте строит `braidctl stats`. Чтобы разобрать проблему у друга, админ временно выдаёт его подписке признак админа и снимает его новой публикацией.

## Почему

Отвергнуто:

- Телеметрия со всех устройств, по умолчанию или по согласию. Заказчик исключил её прямо — «у друзей ничего»; поэтому в клиенте друга отправки просто нет, а не выключена настройкой.
- Локальный журнал у всех без отправки. Заказчик ограничил админом «логи и телеметрию» одной фразой, так что и журнала на диске у остальных нет.

## Последствия

- Статистика описывает только устройства админа. Он сидит на основном хосте, друзья — на дополнительном, поэтому качество дополнительного хоста и сетей друзей по телеметрии не видно, пока админ сам к нему не подключится.
- Пороги автовыбора (ADR 0008) настраиваются по этой узкой выборке и могут не подойти сетям друзей.
- Проблему у друга по умолчанию разбирают по его описанию; журнал появляется только после временной выдачи признака админа.
- Токен телеметрии лежит внутри подписки админа, поэтому утечка этой подписки даёт возможность писать в журналы хоста: беречь её нужно как секрет.
- Гарантия «у друзей ничего» держится на тесте: без признака админа файл журнала не создаётся, а адрес телеметрии не вызывается.
